# Proyecto final del curso

<span class="course-badge">4 semanas · 8 sesiones</span>

## Reto previsto

Crear, individualmente o en pequeño equipo, una solución digital para una necesidad cercana del aula o del centro.

## Condiciones iniciales

- Integrar aprendizajes de al menos tres unidades.
- Mantener una estructura de archivos ordenada.
- Proteger datos personales y respetar licencias.
- Probar el producto con otras personas.
- Aplicar mejoras y explicar las decisiones.

## Entregables previstos

1. Propuesta y planificación.
2. Producto digital funcional.
3. Diario breve de trabajo.
4. Evidencias de pruebas y mejoras.
5. Presentación final.

!!! info "Entrega"
    El proyecto se entregará por fases en Aules. Las instrucciones definitivas se publicarán cuando comience el proyecto.
