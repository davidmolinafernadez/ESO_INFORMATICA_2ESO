# UD2 · Conozco mi ordenador

<span class="course-badge">4 semanas · 8 sesiones</span>

## Pregunta guía

¿Qué ocurre dentro de un ordenador y cómo podemos resolver problemas sencillos sin actuar al azar?

## Aprendizajes previstos

- Hardware, software y periféricos.
- Función de CPU, RAM, almacenamiento y placa base.
- Sistema operativo, aplicaciones, archivos y cuentas.
- Mantenimiento básico, actualizaciones y almacenamiento.
- Diagnóstico seguro y sostenibilidad.

## Producto final previsto

Una guía visual de componentes acompañada de un árbol para diagnosticar incidencias habituales.
