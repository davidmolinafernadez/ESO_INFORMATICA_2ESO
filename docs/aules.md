# Entregas mediante Aules

Esta web sirve para consultar contenidos e instrucciones. **Todo el trabajo puntuable se entrega en Aules**, nunca por correo electrónico ni mediante enlaces enviados por chat.

## Procedimiento de entrega

1. Entra en la tarea correspondiente de Aules.
2. Lee el enunciado y comprueba la fecha límite.
3. Descarga la plantilla si existe.
4. Guarda el archivo con el nombre solicitado.
5. Sube el archivo o pega el enlace en el espacio indicado.
6. Pulsa **Enviar tarea** y comprueba el estado.
7. Conserva tu copia hasta que aparezca la calificación.

## Nombre general de los archivos

`2ESO_UDn_Actividad_ApellidosNombre_v01`

Ejemplo: `2ESO_UD1_A3_GarciaMarta_v01.pdf`.

## Si entregas un enlace

- Comprueba el permiso en una ventana privada.
- Utiliza únicamente el permiso solicitado.
- No borres ni muevas el archivo después de entregarlo.
- No incluyas datos personales innecesarios.

## Correcciones y mejoras

Cuando el profesor permita una nueva versión, conserva el archivo anterior y aumenta el número: `v01`, `v02`, `v03`.

!!! warning "Una tarea guardada no siempre está enviada"
    Antes de salir de Aules, verifica que la tarea figure como **enviada para calificar** y no solamente como borrador.
