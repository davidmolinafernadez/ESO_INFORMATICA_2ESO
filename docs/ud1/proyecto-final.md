# Proyecto final · Guía de supervivencia digital

## Encargo

Crearás una guía visual para ayudar a un estudiante nuevo de 2.º ESO a organizarse, trabajar en la nube y comportarse con seguridad. Debe ser comprensible sin que estés presente para explicarla.

## Formato

Puedes realizarla como presentación, documento visual, pequeño sitio web o infografía multipágina. Antes de empezar, confirma el formato con el profesor.

## Contenido obligatorio

1. Portada, título y autoría.
2. Árbol de carpetas recomendado para el curso.
3. Cinco reglas para nombrar archivos con tres ejemplos.
4. Explicación de local, nube, sincronización y copia de seguridad.
5. Tabla de permisos: lector, comentador y editor.
6. Mini-guía para comprobar una fuente.
7. Decálogo de privacidad, netiqueta y bienestar digital.
8. Una situación problemática resuelta paso a paso.
9. Fuentes y créditos de imágenes.

## Fases

### 1. Boceto

Define audiencia, índice y estilo. Presenta un boceto antes de producir.

### 2. Primera versión

Completa todo el contenido. Prioriza claridad y ejemplos propios.

### 3. Prueba con una persona

Pide a un compañero que encuentre tres datos concretos. Anota cuánto tarda, qué duda tiene y qué cambiarías.

### 4. Mejora y entrega

Aplica al menos dos mejoras y entrégala con el nombre:

`2ESO_UD1_Proyecto_Nombre_vFinal`

## Puntuación

El proyecto representa el **40 % de la unidad**.

!!! warning "Privacidad y autoría"
    No incluyas datos personales reales. Utiliza imágenes propias o con licencia adecuada e identifica su procedencia.
