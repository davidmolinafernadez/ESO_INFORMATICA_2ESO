# 3 · Buscar y comprobar información

## Buscar no es acertar a la primera

Una búsqueda eficaz utiliza palabras concretas. En lugar de escribir `ordenadores`, prueba `consejos seguridad contraseñas adolescentes`.

Puedes mejorarla:

- añadiendo el tema y el tipo de información;
- usando comillas para una frase exacta;
- indicando una institución o dominio;
- cambiando una palabra si aparecen resultados poco útiles.

## Cuatro preguntas para una fuente

1. **Autoría:** ¿quién lo ha creado? ¿Podemos identificarlo?
2. **Fecha:** ¿está actualizado para nuestra pregunta?
3. **Intención:** ¿pretende informar, vender, entretener o convencer?
4. **Contraste:** ¿coincide con otras fuentes fiables?

## Señales de alerta

- No identifica autor ni procedencia.
- Utiliza titulares alarmistas o promete algo increíble.
- Pide compartir inmediatamente.
- Confunde opiniones con hechos.
- Cita estudios o expertos sin enlazarlos.
- Tiene errores o imágenes fuera de contexto.

!!! question "¿Wikipedia sirve?"
    Puede ayudar a orientarse, pero no debe ser automáticamente la única fuente. Revisa las referencias y contrasta la información importante.

## Cómo citar en nuestras actividades

Anota al menos: título, entidad o autor, fecha si aparece, enlace y fecha de consulta. Después explica con una frase por qué te parece adecuada.
