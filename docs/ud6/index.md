# UD6 · Programación y web

<span class="course-badge">6 semanas · 12 sesiones</span>

## Pregunta guía

¿Cómo transformamos una idea en instrucciones que una máquina pueda ejecutar?

## Aprendizajes previstos

- Descomposición de problemas y algoritmos.
- Secuencias, decisiones, repeticiones y eventos.
- Programación visual mediante bloques.
- Estructura básica de una página web.
- Pruebas, errores y mejora iterativa.

## Producto final previsto

Programa interactivo sencillo y página web de presentación del resultado.
