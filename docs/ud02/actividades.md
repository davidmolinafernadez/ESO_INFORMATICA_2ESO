# Actividades · Procesador de textos en la nube

Las cuatro actividades se realizan preferentemente en clase y se entregan en **Aules**.

## A1 · Aplicar estilos a un documento desordenado

**Producto:** archivo o enlace con el nombre `2ESO_UD02_A1_Nombre_v01`.

**Proceso:** sigue la demostración inicial, crea una primera versión, comprueba el resultado y anota una mejora.

**Entrega:** adjunta el producto y una evidencia breve de la comprobación.
