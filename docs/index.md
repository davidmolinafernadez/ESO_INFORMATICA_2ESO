## Cómo trabajaremos

1. Lee o escucha la explicación.
2. Realiza la actividad breve.
3. Guarda el archivo con el nombre indicado.
4. Comprueba la lista antes de entregar.
5. Mejora tu trabajo después de recibir comentarios.
